# Contributing to AI Northwest projects

Welcome. These defaults apply to every repository in the organization unless a repository's own docs say otherwise.

## How we work

1. **Changes arrive by pull request.** Branch from the default branch with a `feature/`, `fix/`, `chore/`, or `docs/` prefix and a short kebab-case slug.
2. **Commits:** one logical change per commit, Conventional Commits style (`fix:`, `feat:`, `docs:`, `chore:`).
3. **Pull requests:** keep them small and fill in the Captain's Card template. The **Proof** field matters most: show how you checked that the change works.
4. **Secrets:** never commit tokens, keys, credentials, or `.env` files. If you spot one, report it privately (see SECURITY.md) rather than opening a public issue.

## First time here?

Open an issue on the repository you want to help with and say what you have in mind. Community contributions are the point of this organization, and someone will help you find your footing.

## Account expectations

Collaborators are expected to have two-factor authentication enabled on their GitHub account.
