# AI Northwest

A community for people building with AI in the Pacific Northwest.

We run meetups, coffee socials, and hands-on sessions around Seattle, and we build the open tooling that keeps the community running: event infrastructure, AI Northwest Radio, kiosks and receivers, and agent setup guides.

## Get involved

- Come to an event. Everyone from the AI-curious to full-time practitioners is welcome.
- Contribute to the projects here. Most repositories accept pull requests, and the contributing guide in this repository explains how we work.
- Bring a question. The community exists so different kinds of minds, human and otherwise, can understand each other better.
